# AgriConnect
AgriConnect adalah platform berbasis web yang dirancang untuk menghubungkan petani, pemilik lahan, dan pembeli. Aplikasi ini bertujuan untuk mempermudah manajemen lahan pertanian, proses verifikasi petani, hingga transaksi hasil bumi atau penyewaan lahan secara transparan dan efisien.

# Deskripsi AgriConnect
AgriConnect dibangun untuk mendigitalisasi sektor pertanian dengan menyediakan ekosistem yang terintegrasi.

# Fitur Utama
1. Manajemen Lahan pascapanen : Petani dapat menawarkan lahan untuk dipanen (sistem tebasan), namun fitur ini sebatas hanya menghubungkan petani dengan penebas lahann, tanpa transaksi langsung.
2. Registrasi, login, dan Verifikasi Akun oleh admin untuk memastikan petani dan lahan valid
3. E-Commerce Produk pascapanen : Pembeli dapat mencari hasil bumi atau lahan melalui katalog yang tersedia.
4. Sistem Chat: Memungkinkan negosiasi langsung antara penyedia dan pencari lahan (pengembangan setelah ets)
5. Dashboard Statistik oleh admin untuk memantau perkembangan web.
